# Hi, I'm Shushant 👋

I work on machine learning research: quantum ML and quantum error correction, robustness and safety of AI agents, and small efficient models. I also build the tools I use every day.

Every research repo ships a `LIMITATIONS.md` and pre-registered hypotheses, so the numbers mean what they say.

## Research

| Project | What it asks |
|---|---|
| [**SurgeryNet**](https://github.com/Shushant17711/surgerynet) | Can a learned decoder handle lattice surgery? A GNN decoder with learned-decoder accuracy on merge/split operations, including timelike errors. |
| [**EntangleRSA**](https://github.com/Shushant17711/EntangleRSA) | What does entanglement buy a quantum RL policy? Compares PQC and MLP PPO policies with representational similarity analysis across entangling depths. |
| [**DequantEngine**](https://github.com/Shushant17711/TensorEngine) | Given a trained quantum classifier, builds the closest classical tensor-network surrogate and reports where it catches up. |
| [**Mirage**](https://github.com/Shushant17711/mirage) | A controlled adversarial web for measuring how browser agents fail under prompt injection. |
